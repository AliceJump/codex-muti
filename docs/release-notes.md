# Codex Pool 0.1.0

Windows x64 自包含便携版正式发布：完整解压后双击 CodexPool.exe，无需另装 .NET 或 PowerShell 7。

- 移除客户端用量改写、HTTPS 后端及实验压缩桥接，模型代理继续独立工作。
- Token、请求和切换记录持久化，支持日期筛选及分页，重启后继续查看。
- 拆分账户浮窗与代理托盘职责，并支持互相启动／显示；已有实例直接复用。
- 保留各账户的真实额度、独立授权及现有阈值。

本包不包含官方 Codex CLI／Desktop；原生登录需要可执行的官方 `codex` 命令。旧配置中的本地 `chatgpt_base_url` 应移除，继续使用 `openai_base_url` 接入模型代理。

已知限制：未签名；完整跨账户长会话与所有桌面场景尚未完成验收。原生 UI 有已知动画时序波动，不能将发行包构建成功视为真实账户验收通过。升级前应正常关闭代理及两个客户端，再完整替换程序文件，用户数据仍保存在 LocalAppData。

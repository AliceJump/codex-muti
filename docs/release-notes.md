# Codex Pool 0.1.1

Windows x64 自包含便携版：完整解压后双击 CodexPool.exe，无需另装 .NET 或 PowerShell 7。

- 启动后打开 Dashboard 并添加托盘图标，后台和重复启动不展开账户卡片或右键菜单；保存过固定状态的面板也在主动展开时恢复。
- 修复托盘“刷新额度”“打开账户管理与用量”等操作受事件连接状态误禁用的问题。控制请求独立读取本地授权，状态定时更新并有超时保护，失败时显示明确提示。
- Dashboard 按变化更新数据，保留输入内容、焦点、滚动位置和已经加载的请求历史，不再因后台更新清空整块面板。
- 详细浮窗按每个账户分别显示今日 Token 用量，以及缓存输入／未缓存输入横条、数量和占比；不合并账户，缓存明细缺失时显示待确认。
- 桌面组件部署同步更新已经运行的两个托盘，避免账户界面与代理菜单混用旧版本；仅组件部署保留代理进程。

本包不包含官方 Codex CLI／Desktop；原生登录需要可执行的官方 `codex` 命令。旧配置中的本地 `chatgpt_base_url` 应移除，继续使用 `openai_base_url` 接入模型代理。

已知限制：未签名；完整跨账户长会话与所有桌面场景尚未完成验收。界面和合成回归不替代真实账户验收。升级前应正常关闭代理及两个客户端，再完整替换程序文件，用户数据仍保存在 LocalAppData。

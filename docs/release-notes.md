# Codex Pool 0.1.2

Windows x64 自包含便携版：完整解压后双击 CodexPool.exe，无需另装 .NET 或 PowerShell 7。

- 修复点击账户额度托盘图标时，旧的完整面板先闪现、消失后才播放入场动画的问题。
- 账户面板每次打开都从较矮的状态平滑展开，直接点击托盘与“打开账户浮窗”使用一致的显示效果。
- 后台刷新不再提前消耗准备中的入场动画；快速关闭、再次打开不会触发上一轮遗留的显示回调。
- 面板已经显示时，重复打开只激活现有面板，避免重新定位打断显示。

验证：Windows 本地完整 UI 回归 34/34 通过；正式包由 GitHub Actions 完成构建、安全检查与解压离线启动验证后发布。

本包不包含官方 Codex CLI／Desktop；原生登录需要可执行的官方 `codex` 命令。旧配置中的本地 `chatgpt_base_url` 应移除，继续使用 `openai_base_url` 接入模型代理。

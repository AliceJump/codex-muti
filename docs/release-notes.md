# Codex Pool 0.1.5

Windows x64 自包含便携版：完整解压后双击 CodexPool.exe，无需另装 .NET 或 PowerShell 7。

- 账户弹出面板支持触摸点选、滑动、长按查看完整信息及固定后的触摸拖动。启用 Windows Pointer 输入，并过滤重复的触摸兼容鼠标消息，修复触摸事件丢失和一次触摸重复操作。
- 托盘菜单支持触摸展开子菜单、点选和长列表滑动；触摸设备增加菜单行高，触摸展开的子菜单不再依赖鼠标悬停保持显示。
- 悬停信息统一圆角、留白、自动换行及浅色、深色、高对比度样式。主题按钮按当前显示的明暗直接切换，浅色点一次即变深色，不再经过外观相同的“自动”档位。
- Web 控制台重整账户、用量与设置界面，支持固定本机网址直达、账户切换记录分页及增量更新。
- 新增供本机应用与机器人使用的 OpenAI 兼容模型接口、独立访问密钥、模型目录及生图适配；具体支持范围见包外的项目文档，不代表兼容所有客户端或参数。
- 改进订阅续费后的额度和套餐同步、历史缓存与订阅元数据时效；重新授权成功后及时恢复账户可用状态，保留用户手动设置的暂停、禁用和排空状态。
- 原生登录支持取消与重复登录保护，并在取得代理独占锁后清理强制停止遗留的登录临时目录；限制上游读取及额度锁等待时间，并仅在实际尝试备用账户时准备其凭据，减少不必要的刷新。
- 新增部署快捷入口与强制部署选项，桌面组件可单独更新。强制部署核心会中断当前请求与登录，应在明确需要时使用。

验证：本地桌面构建通过；触摸功能初版通过 44 项 UI 回归，随后对 Pointer 输入配置、兼容鼠标识别及隔离面板的点选/滑动做了定向检查。实体触摸屏、全模式、多显示器的完整端到端验收仍待完成。正式发行包须由 v0.1.5 标签触发 GitHub Actions，完成构建、核心/安全测试、客户端定向检查、Dashboard 测试、自包含打包和 ZIP 解压离线验证后才公开发布。

本包不包含官方 Codex CLI／Desktop；原生登录需要可执行的官方 `codex` 命令。旧配置中的本地 `chatgpt_base_url` 应移除，继续使用 `openai_base_url` 接入模型代理。

已知限制：发行包未签名；Mac Widget 仅为源码原型，未进行原生 Mac 编译或真机验收；完整跨账户长会话、真实多账户故障矩阵与机器人客户端集成仍未完成验收。订阅日期依赖上游可用 ID token 元数据，不提供则显示未知。升级前请正常关闭代理及两个客户端，再完整替换程序文件；用户数据仍保存在 LocalAppData。

# 额度与 Token 统计

额度沿用各原生注册的官方 usage 快照，显示 5 小时／周剩余百分比、重置时间和更新时间。超过 2 分钟、时间异常或已过重置点的窗口显示待确认；Web、悬浮窗、胶囊和托盘采用相同有效期。额度百分比独立于 Token 用量，不按 Token 估算套餐剩余额度。

Web 的「Token 用量」支持今日、最近 7 天、累计，分别按账户和请求模型汇总，同时展示每日趋势和最近请求的输入／输出、缓存／推理明细。完整模式悬浮窗显示各账户今日用量，详细统计在 Web 面板查看。

```powershell
.\scripts\pool.ps1 statistics
```

本地鉴权的 `GET /statistics` 返回完整汇总；`GET /status` 及 `/events` 快照的 `tokenStatistics` 使用同一结构。浏览器安全会话和本地访问密钥均可读取，官方模型入口的凭据不能访问统计控制接口。原有 `/usage` 返回结构保持兼容。

## 统计口径

- 只记录经过本代理、已经进入模型传输的 HTTP 请求。从新版本启用后开始，不能回补历史或统计其他客户端直接访问上游的用量。刷新额度、读取模型目录和请求准入前失败不计入请求数。
- 每次代理请求结算一次。安全切号后归属实际上游账户；被明确拒绝的前置尝试不重复计入请求数。同一请求内重复 usage 事件只取第一份有效终态用量。客户端重新发起的独立请求分别计数。
- 只读取 `response.completed`、`response.incomplete` 或 `response.failed` 终态 Response 的有效 `usage`。不累计 delta，不用 EOF 或文本长度推算。最大观察事件为 2 MiB，超限事件不改变转发内容，缺少可验证 usage 的用量显示未报告。
- `input_tokens`、`output_tokens`、`total_tokens` 必须为非负整数，且总量与输入＋输出一致。缓存是输入子集，推理是输出子集，均不再加入总量；可选明细缺失或无效时保留未知。字段依据 [OpenAI Responses streaming events](https://developers.openai.com/api/reference/resources/responses/streaming-events) 与 [Counting tokens](https://developers.openai.com/api/docs/guides/token-counting)。
- 上游已经发送完整终态 usage，即便对应下游写入失败也记录报告的消耗。中断、取消或失败时没有完整 usage，则请求数增加、Token 用量未知。未报告请求及明细覆盖数单独显示；部分覆盖下展示的是已报告部分的合计。
- 日期按代理主机的本机时区、请求结算时间划分；最近 7 天为今天及前 6 个自然日。接口显示时区。日桶保留 90 天，累计桶继续保留，删除账户后历史保留并显示「已移除账户」。统计模型是请求中的 model 名称，不把它当作计费型号或金额。

## 存储

统计写入 Daemon 数据目录下独立的 `usage.dpapi`，只包含注册 ID、模型名称、日期和数值计数，不保存 prompt、响应内容、工具参数／结果、Response ID 或凭据。采用 Windows DPAPI CurrentUser 加密、数据目录 ACL 和临时文件原子替换，不重写账户凭据文件。

后台每 2 秒合并保存一次，正常关闭时再次保存；强制结束或系统崩溃可能丢失最后一个保存周期。写入失败保持内存数据并重试，页面显示等待保存。历史无法读取或解密时显示历史不可用，保留原文件并停止覆盖，当前运行期的统计只存在内存中。

## 验证范围

新增合成测试覆盖字段校验、缺失明细、分片／多行／CRLF、重复终态、大事件／超限事件、下游写入失败、安全切号归属、加密保存及恢复、跨午夜、90 天保留、1000 个并发结算和写入失败重试。原生 UI 测试覆盖今日用量、未报告区别和三布局过期／重置额度。隔离浏览器验收覆盖时间范围切换、账户／模型汇总及窄屏布局。

这些测试不证明真实账户的 Token 报告完整性、缓存命中或跨账户计费行为。自然额度耗尽／恢复及真实缓存验收继续以原验收文档为准。当前运行的旧代理未被替换；按仓库部署流程启用新版本后才开始真实统计。

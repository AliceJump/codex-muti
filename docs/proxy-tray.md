# 代理控制托盘

Windows 通知区域现在可以同时保留两个图标：原有数字额度图标是账户面板；Codex Pool 标志图标是代理控制。两者使用独立进程、单实例锁、Explorer GUID 和稳定安装目录。退出账户面板不会退出代理控制图标或停止代理。

代理图标左键或右键打开简短菜单：

- 打开账户管理：进入本机 Dashboard。
- 切换到账户：只影响下一次模型请求，已接受请求仍使用原账户。
- 开启／关闭自动切换：保留现有额度阈值。
- 更新额度：沿用代理的真实额度更新接口。
- 关闭代理：停止模型代理，图标保留；离线后菜单提供“启动代理”。
- 退出代理托盘（代理继续运行）：只关闭这个控制图标。

新版代理通过仅接受本地 bearer 的 `POST /control/shutdown` 平滑退出，先返回确认，再停止接受新连接，最多等待 30 秒排空已有请求。关闭时若仍有模型请求，会提示可能中断。旧代理没有关闭接口时，需额外明确确认直接关闭；此时核对 127.0.0.1:3210 的监听 PID、启动时间、进程名称及本仓库 `.local` 中的发布路径。不会停止 Codex、桥接、账户面板或其他服务，也不会重试或重放模型请求。

代理托盘只在用户点击“启动代理”时启动服务。离线轮询和退出界面不会自动重新拉起服务。启动采用当前本地构建指针，账户与阈值保留；若本次托盘观察到压缩实验模式，重新启动代理时沿用它。首次通过 Codex Pool 一键入口启动时，也明确传入压缩模式。

独立构建并启动控制图标，不重启正在运行的代理、账户面板或 Desktop：

```powershell
pwsh -NoProfile -File scripts/build-proxy-tray.ps1
pwsh -NoProfile -File scripts/start-proxy-tray.ps1
```

构建保存到 `.local/proxy-tray/builds/`，安装到稳定的 `.local/desktop/Proxy/`。已有控制托盘运行时沿用旧实例；更新后请通过它的“退出代理托盘”再启动新版本，代理不必退出。账户面板部署不会关闭这个独立控制进程。

安装后，桌面 **Codex Pool** 快捷方式、`start-local.ps1` 和 `open-widget.ps1` 都会同时启动代理控制图标；重复启动仅唤醒现有控制菜单。新版平滑关闭能力需要新版 Daemon 实际运行，构建并不会替换运行中服务。

验证覆盖独立托盘 GUID、非默认阈值保留、进程路径限制、关闭 API 鉴权、账户面板部署隔离。真实代理关闭没有作为自动化测试执行；该操作由用户通过菜单明确发起。

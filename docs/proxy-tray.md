# 代理控制托盘

Windows 通知区域现在可以同时保留两个图标：原有数字额度图标是账户面板；Codex Pool 标志图标是代理控制。两者使用独立进程、单实例锁、Explorer GUID 和稳定安装目录。退出账户面板不会退出代理控制图标或停止代理。

代理图标左键或右键打开简短菜单：

- 代理在线／离线：显示服务状态，在线时同时显示本机地址。
- 打开账户浮窗：已有账户客户端时直接显示原面板，未运行时从当前构建安装并启动独立客户端。代理离线也能打开；这个操作不启动代理。
- 关闭代理：停止模型代理，图标保留；离线后菜单提供“启动代理”。
- 退出代理托盘（代理继续运行）：只关闭这个控制图标。

账户选择、自动切换、额度刷新与账户管理／历史用量统一放在数字额度图标的右键菜单。账户菜单提供“启动代理”（离线）或“打开代理控制”（在线）：前者启动服务后拉起控制图标，后者复用已有服务和控制客户端。自动切换保留现有额度阈值；切换账户只影响下一次模型请求。

新版代理通过仅接受本地 bearer 的 `POST /control/shutdown` 平滑退出，先返回确认，再停止接受新连接，最多等待 30 秒排空已有请求。关闭时若仍有模型请求，会提示可能中断。旧代理没有关闭接口时，需额外明确确认直接关闭；此时核对 127.0.0.1:3210 的监听 PID、启动时间、进程名称及本仓库 `.local` 中的发布路径。不会停止 Codex、账户面板或其他服务，也不会重试或重放模型请求。

离线轮询和退出界面不会自动重新拉起服务。代理与账户菜单中的“启动代理”使用当前本地构建指针，账户与阈值保留。打开／再次显示账户面板不会重新启动已关闭的代理；未运行的客户端通过稳定安装目录启动，已运行时使用原有单实例信号唤醒。

独立构建并启动控制图标，不重启正在运行的代理、账户面板或 Desktop：

```powershell
pwsh -NoProfile -File scripts/build-proxy-tray.ps1
pwsh -NoProfile -File scripts/start-proxy-tray.ps1
```

独立构建保存到 `.local/proxy-tray/builds/`，安装到稳定的 `.local/desktop/Proxy/`。启动时选择完整构建和独立代理托盘构建中最后更新的指针，避免完整部署后又选回旧版本。单独启动时沿用已有实例；`deploy.cmd` 的全部／桌面组件部署会一起更新账户托盘和已经运行的代理托盘，失败时尝试恢复两者；仅部署核心保留两个 UI 进程。

安装后，桌面 **Codex Pool** 快捷方式、`start-local.ps1` 和 `open-widget.ps1` 都会同时启动代理控制图标；重复后台启动不展开控制菜单。只有用户主动点击图标或选择打开代理控制时才显示菜单。新版平滑关闭能力需要新版 Daemon 实际运行，构建并不会替换运行中服务。

# Codex Pool Windows 测试版

将整个 ZIP 解压到固定文件夹，双击 **CodexPool.exe**。软件会显示账户浮窗和独立的代理控制图标，不需要安装 .NET、PowerShell 7 或以管理员身份运行。支持 Windows 11 x64。

- 数字额度图标：选择账户、自动切换、刷新额度、打开账户管理与历史用量。可以固定／隐藏浮窗，离线时可以启动代理。
- Codex Pool 图标：查看代理状态、启动／关闭代理、打开账户浮窗。退出任一托盘界面都不会停止代理；停止服务请使用“关闭代理”。
- 右键菜单可以互相拉起另一个客户端，已有进程会复用。打开账户浮窗不会重新启动已关闭的代理。
- 添加原生账户仍需要安装官方 Codex CLI，并确保终端可以执行 `codex`。本软件不包含官方 CLI／Desktop，也不会替你修改 Codex 配置或登录。
- 模型入口为 `http://127.0.0.1:3210/v1`。已有本地 `chatgpt_base_url` 配置应移除，ChatGPT 后端继续使用官方服务。

数据保存在当前 Windows 用户的 `%LOCALAPPDATA%\CodexPool`（设置过 `CODEX_POOL_DATA_DIR` 时使用该目录），账户及历史使用 DPAPI 加密。Token 和请求历史不会按七天自动清理，可按日期筛选；更换程序目录不会清空数据。不要分享该数据目录。

升级前先结束请求，通过代理菜单关闭服务，并分别退出两个托盘客户端；随后将新版本完整解压到原来的程序位置，不要只复制 EXE。不要在运行时覆盖文件。重新启动后沿用账户、阈值和历史记录。备份数据应先正常退出代理。

此版本未签名，Windows 可能显示未知发布者；下载请使用本项目 GitHub Releases，并核对同页 SHA256SUMS.txt。没有完整跨账户长会话及全部桌面场景的发布验收，本版作为预发布提供；界面与真实账户限制见项目文档。

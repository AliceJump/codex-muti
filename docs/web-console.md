# 网页控制台

启动代理后，直接访问 [Codex Pool](http://127.0.0.1:3210/)。无需命令行、票据链接、Cookie 或浏览器登录；服务重启后页面会重新连接。托盘小组件的「打开 Web」与 `dashboard` 命令都打开这个固定地址。

完整功能分为五个区域：

- **账户与额度**：当前账户、自动切换状态、进行中的请求、可用账户数，各账户的真实额度窗口、余额和今日用量。账户详情中查看订阅、套餐来源、数据更新时间，以及暂停、排空、启停、改名、重新登录和删除操作。
- **用量统计**：今日、最近 7/30 天、全部历史或自选日期，查看总量、缓存、推理、按账户和模型汇总及每日用量。未报告用量保持未知。
- **活动记录**：账户切换与模型请求分别展示。账户页仅预览最近 3 条切换；活动页查看最近 100 条，每页 8 条，可筛选手动或自动切换。查看旧页时固定当前记录，新记录到达后提示返回第一页查看，避免列表跳动。日期包含年份，删除账户后的历史保留。
- **应用接入**：复制 OpenAI 兼容地址、查看模型目录、创建和撤销模型密钥。新密钥仅显示一次。
- **偏好设置**：自动切换、额度窗口阈值，以及本地服务信息。未保存的设置不会被实时状态更新覆盖。

控制台支持窄屏布局和系统深浅主题。它是完整管理入口，小组件保留快捷查看与切换用途。

代理仍只监听 `127.0.0.1:3210`，检查 Host、Origin 和跨站请求，不开放 CORS。网页请求使用非简单请求头；其他网站的 HTML 表单不能直接提交账户操作。这里没有会话状态或限时授权，能够访问本机的进程可以使用本地管理接口。模型调用及关闭服务继续使用各自的密钥。
